# __PACKAGE__

This package is a personal Codex CLI distribution built from [__REPO__](https://github.com/__REPO__).

The main package installs a `codex` launcher and an optional platform package containing the native binary for the current operating system and architecture.

## Install

```sh
npm install -g __PACKAGE__
```

If the official CLI is already installed globally, remove it first because both distributions provide the `codex` command:

```sh
npm uninstall -g @openai/codex
```

Verify the installation:

```sh
codex --version
```
